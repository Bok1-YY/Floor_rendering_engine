# 🪵 Floor AI · 地板效果图生成引擎 — 知识库首页

> 面向**地板行业**的 AI 效果图生成工具：上传地板小样 → 自动识色 + 智能配方 → 配置场景参数 → 调 Gemini / Fal 出图，支持 **4K**、快出（B2）与精修（Pro）双档。
> 后端 **FastAPI 无头服务** + 前端 **Next.js**，前后端解耦、异步作业队列、SSE 实时进度。
>
> 本知识库由 [[开发日志]]（`开发日志.md`，`2026-06-16 → 2026-07-09`）+ 当前代码结构提炼而成。**这是首页（MOC）**，从这里出发去任何一篇核心笔记。

## 🧵 项目主轴（三句话看懂演进）

1. **起点**：从 NiceGUI 单体 `floor_engine/` fork 出商业主线 `Floor_engine_server/`，走[[mental-model|绞杀者迁移]]换成 FastAPI 无头 + Next.js（引擎零改）。
2. **根治长请求**：出 4K 图的长连接会被公司软路由 reset → 改[[architecture|异步作业队列 + SSE]]，`POST` 秒回 `job_id`。
3. **保真是生命线**：所有创意改动（配方 / [[mental-model|Omakase]] / 预览）都以「[[mental-model|地板技术层逐字节锁死]]」为前提。

## 📌 元原则速记（贯穿全程）

- **引擎零改** — UI 只是引擎的皮。
- **保真锁死，创意放开** — 一锁一放。
- **Golden + 字节比对** — 提示词保真的唯一自动护栏。
- **本机自用校准** — [[pitfalls-and-conventions|拒绝过度工程]]。
- **诚实标注验证边界** — 自动验证 vs 真机人眼确认；生图质量走 human-loop 人工评审。
