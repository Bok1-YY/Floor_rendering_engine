# 独立样品校色工具

> 让不同时间、不同面积拍摄的新旧样品图，重新回到同一产品色基准。

把“新拍摄的大面积样品图”的颜色调成“以前的小面积样品图”的样子，同时保留新图的原始分辨率、木纹、压纹、倒角和真实光影。适合设计、样册、电商和社媒团队在正式排版或生图前快速统一产品素材颜色。

它复用了 Floor Engine 已验证的 LAB 对色能力，并新增可靠像素筛选、精细颜色分布迁移、空间光照校正和质量报告。程序可以完全脱离主系统运行：图片只在本机处理，不上传、不联网，也不产生任何 AI 模型费用。

## 能做什么

- 鼠标框选新图中的纯材料区域，避开背景、手、色卡和强反光。
- 默认只匹配颜色，保留新照片的亮度层次与表面质感。
- 可切换“颜色 + 明暗”，同时拉近两次拍摄的曝光表现。
- 0–100% 强度控制，先预览，再输出原尺寸图片。
- 支持 JPG、PNG、TIFF、BMP 和 WebP；大图采用分片处理，控制内存占用。
- 同时提供桌面界面和批处理友好的命令行入口。
- 默认“经典”模式保持原有快速、稳定的统计校色；“精细”模式可进一步匹配复杂、偏斜或多峰颜色分布。
- 自动排除过曝/欠曝、镜面反光、深阴影和异色离群点；诊断图用绿、红、蓝、黄标出可用与问题像素。
- 可选空间光照校正：只均衡渐变色偏，或同时均衡色偏与明暗；默认关闭，避免不必要地改变真实光影。
- 每次分析给出 0–100 可信度、可用像素比例、预计 CIEDE2000 色差、色域风险和可执行警告；低分会提示，但仍允许保存。

## 图形界面

Windows 直接双击 `启动校色工具.bat`；Linux 可运行 `sh 启动校色工具.sh`。也可以运行：

```powershell
python app.py
```

使用顺序：

1. 打开新拍的大面积图片。
2. 打开以前的小面积参考图。
3. 如果新图包含背景、手、色卡或大面积反光，用鼠标在新图上框出一块干净、均匀、能代表材料本色的区域；否则保持整图取色。
4. 默认使用“只匹配颜色”，它会保留新图原有明暗、纹理和光影。只有两次拍摄曝光差异也需要统一时，才选择“颜色 + 明暗”。
5. 先生成预览，按需要调整强度，再保存全分辨率图片。

“算法”建议先保持 `classic`。当材料本身包含明显深浅层次、颜色分布不对称，或经典模式只对准了平均色时，再选 `distribution`。只有新图存在大面积渐变色偏或混合光时才开启空间光照；选择 `chroma` 或 `full` 会自动启用精细算法。

质量诊断图的颜色含义：绿色是参与计算的可靠像素，红色是反光或过曝/欠曝，蓝色是局部深阴影，黄色是与主体材料色差过大的离群点。分数较低时优先重新框选一块更干净的材料区域。

建议两张图先使用相同白平衡/色彩空间，并避开过曝、强阴影和反光。这个工具做的是统计校色，不会复制旧小样的木纹或纹理。

## 命令行

```powershell
python app.py --source 新大图.jpg --reference 旧小样.jpg --output 校色结果.jpg
```

可选参数：

- `--strength 0.85`：校色强度，范围 0~1。
- `--rect 0.1,0.2,0.7,0.6`：在新图上用于取色的归一化选区 `x,y,宽,高`。
- `--match-luminance`：除颜色外也匹配明暗；不加时保留新图明暗。
- `--algorithm classic|distribution`：经典统计映射或精细颜色分布匹配，默认 `classic`。
- `--illumination off|chroma|full`：关闭空间校正、仅均衡色偏，或同时均衡色偏与明暗；非 `off` 会自动使用精细算法。

精细模式示例：

```powershell
python app.py --source 新大图.jpg --reference 旧小样.jpg --output 校色结果.jpg --algorithm distribution --illumination chroma
```

## 独立安装

只需 Python 3.10+，然后在本目录运行：

```powershell
pip install -r requirements.txt
```

程序只依赖 Pillow、NumPy 和 OpenCV，不需要启动 Floor Engine 服务，也不需要网络或 AI 接口。

## 算法边界

这是确定性的本地图像算法，不是生成式 AI。它能统一同一材料在不同拍摄条件下的颜色统计，但不能恢复已经过曝丢失的纹理，也不能替代相机 RAW/ICC 色彩管理、标准色卡和受控灯箱。要做印刷或实验室级绝对色度交付，仍应使用校准显示器、色卡与仪器测色；本工具更适合日常样册、电商和内容生产中的视觉一致性。
