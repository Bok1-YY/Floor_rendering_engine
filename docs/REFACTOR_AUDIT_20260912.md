## 实现边界

- `api.py` 是兼容入口；`providers/{gemini,fal,inpaint,comfyui,analysis,diagnostics,shared}.py` 持有真实实现。图像生成调度返回 `ProviderCallOutcome`，低层调用保留历史 tuple/字符串兼容协议。
- `routes_jobs.py` 注册 HTTP 端点；`job_service.py` 执行生成、重试和编辑流程；`job_execution.py` 保存 provider 队列句柄。
- `whole_home_design.py` 保留项目建立、户型分析、设计提示词与公开视图，兼容导出原名称；`design_store.py`、`design_images.py`、`design_structure.py`、`design_modeling.py`、`design_provider.py`、`design_schema.py`、`design_exports.py` 各自持有实现，没有反向依赖兼容入口。
- 测试替身现在注入实际实现模块及其显式导入边界，而不是依赖 `sys.modules` 别名。离线测试禁止未替换的 Requests HTTP 请求，防止模块迁移后替身失效时意外联网。
- 现有 URL 与成功字段保留。新增可选 `snapshot_at`；前端 `ApiError` 保留 status、detail、code、Retry-After。409 显示保留草稿的版本冲突操作，429 显示队列拥塞提示，不自动重复提交付费请求。

## 数据兼容与恢复

没有数据库迁移或运行数据清理。队列仍使用 schema v3 JSON；新程序读取旧记录并补齐既有模型字段。新写入保留全部活动任务，终态历史最多 60 条。

旧九问问题按需迁移，不重写全库。分析操作 ID、分来源问题字段均为增量字段；旧项目没有这些字段时使用兼容默认值。程序重启将未完成的普通附加操作标为中断失败，将户型分析恢复为待重新发起，将本地模型任务保留为中断历史。已有 Fal request_id 可走原队列恢复；不会自动重新提交未知结果的付费请求。

建议回退代码前先备份运行目录。旧程序的队列持久化仍只保留最近 60 条，回退后再次写入可能丢弃较旧的活动卡片。图片与记录文件不因队列卡片清理而删除。

## 验证方式

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe tools/verify.py --integration
```

默认不带 `--integration` 时排除需要真实 Blender 的集成用例；`--backend-only` 仅验证 Python。前端首次准备：

```powershell
cd web
npm ci --ignore-scripts
npx playwright install chromium
npm run check
```

`npm run check` 顺序运行类型检查、ESLint、17 项既有前端检查、静态构建和浏览器测试。浏览器测试由隔离的 Python/FastAPI 静态服务托管真实 `web/out`，外部业务接口由测试替身提供；运行目录使用临时路径，退出后清理。

本次验收：后端 **324 通过、1 跳过**（包含真实 Blender/IFC）；前端类型检查、ESLint、17 项既有检查和静态构建通过；**6 项浏览器行为测试通过**；npm audit 为 **0 项漏洞**。唯一原有素材跳过项是 `test_film_repeat_floor` 所需操作员彩膜回归文件缺失；真实 Blender/IFC 测试单独标记为 integration。

## 实际限制

- 服务仍为单 worker。共享状态锁和任务管理器不提供多进程或多用户隔离。
- 15 秒是应用等待后台收尾的期限，不是整个进程退出的硬保证。已进入底层阻塞网络调用的 Python 线程可能等待网络超时；取消等待协程不能安全杀死线程。中断记录用于下次启动恢复。
- 自动回归使用替身验证云模型行为，不验证真实付费 provider 可达性、生成质量或真实账单。保留用户显式确认可能重复计费的交互。
- 本次验证源码运行、静态构建、真实本地 Blender/IFC 与冻结运行适配分支；未重新生产完整 Nuitka 安装包，未在另一台全新 Windows 机器验证安装。
- 大型图像编辑画布和复杂提示词规则没有为缩减行数而重写；本轮提取的是生命周期、服务边界与存在竞态的状态管理。后续改动应继续依赖行为测试渐进进行。
